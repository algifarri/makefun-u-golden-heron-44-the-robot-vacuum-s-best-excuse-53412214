The funniest one-line excuse a robot vacuum gives for missing a spot, written to /output/entry.txt by a tiny deterministic Python program. The line: the vacuum mapped a corner as a lake, refuses to swim, and declares the dust there protected by maritime law.

## The line

> I mapped that corner as a lake, and I do not swim. The dust there now lives under maritime law.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
